皮糙肉厚的红警（由 AI 制作）
================================

把所有单位、建筑、树木、桥梁的血量改成 1500 —— 也就是原版船厂的血量。
支持两个版本：原版红警2（rules.ini）和 尤里的复仇（rulesmd.ini）。

【怎么用】
1. 需要 Python 3（安装时勾选 Add Python to PATH）
2. 原版：双击「一键应用.bat」
   尤里：双击「一键应用(尤里).bat」
   然后把游戏目录拖进去后回车（也可以直接把游戏文件夹拖到 bat 图标上）
3. 完全退出游戏，重新打开
4. 新开一局 / 从"新战役"进关卡 —— 不要读旧存档！
   红警的存档自带当时的场景数据（含各类型血量），读旧档会继续用旧数值。

【撤销】
原版：双击「撤销还原.bat」
尤里：双击「撤销还原(尤里).bat」
会从游戏目录下的 _tanky_backup / _tankymd_backup 还原。

【只看状态、不改东西】
命令行里跑：
    python apply_tanky_mod.py "游戏目录" --check
    python apply_tanky_mod.py "游戏目录" --yr --check

【改了什么（概要）】
- rules.ini：全部血量 1500 + 给 [DeathDummy] 补 1500 + 降负载（碎片/烟尘变少）
- rulesmd.ini（尤里）：全部血量 1500 + 补 8 个 0 血类型 + 降负载
- 任务包/地图里的"地图自带血量覆盖"：全部按 1500 归拢（等长替换，文件大小不变）
  原版 125 处、尤里 85 处
- 任务图里原本就比船厂更硬的目标/地标（纽约大楼 50000、核电站 32000、苏军基地 30000、
  苏/尤里的灯柱 6000、CALAB 25000 等）保留任务原值 —— 不然关卡会直接废掉
- 原版盟军第一关的自由女神像单独加厚到 99999（守得住才行）
- game.exe / gamemd.exe 保持原版不打补丁（5 血那个维修补丁会让 1500 血的维修费翻 5 倍）

【注意】
- 尤里的复仇用的是"往游戏目录放一份散装 rulesmd.ini"的方式盖住打包里那份，
  打包文件（expandmd01.mix / ra2md.mix）一个字节都没动。
- 仅供单机娱乐，别拿去联机。
- 本包不包含任何游戏本体文件。
