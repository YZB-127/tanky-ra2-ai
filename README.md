# 皮糙肉厚的红警（由 AI 制作）

> 把所有单位、建筑、树木、桥梁的血量全部改成 **1500** —— 也就是**原版船厂**（`[GAYARD]` / `[NAYARD]`）的血量。
> 步兵跟船厂一样硬，坦克要磨很久才死，一枪一栋楼？不存在的。
>
> 本仓库**不包含任何游戏本体文件**，只提供规则文件、一键脚本与技术文档。请自备正版游戏。
> 姐妹玩法（另一个极端）：[crispy-ra2-ai](https://github.com/YZB-127/crispy-ra2-ai) —— 全员 5 血，一枪一栋楼。

---

## 这个玩法是什么

| 项目 | 原版 | 皮糙肉厚 |
|---|---|---|
| 步兵 | 75 ~ 125 | **1500** |
| 载具 / 飞机 | 300 ~ 800 | **1500** |
| 建筑 | 750 ~ 1500 | **1500** |
| 树木 / 桥梁 | 200 / 1500 | **1500** |
| 结果 | 正常交火节奏 | **谁都得磨半天，步兵都啃不动** |

选 1500 是因为它正好是**原版船厂的血量**，也就是"全员按船厂的硬度来"。所以这个模式更接近"拆迁队 vs 钉子户"：海量单位围着打也拆不快，油桶连锁、核电站殉爆那种一炸一片的爽感会被大幅削弱——那是 5 血版的乐趣，不是这版的。

---

## 刻意保留原值的 25 处（不然关卡会打不了）

任务图里**原本就比船厂更硬**的东西，是关卡作者专门做硬的目标/地标。把它们压到 1500 会让关卡直接废掉（自由女神像守不住、必须拆的目标一碰就碎），所以一律**保留任务原值**：

| 位置 | 类型 | 原值 |
|---|---|---|
| 盟军任务 `maps01.mix` | 纽约大楼 `CANEWY12` / `CANEWY18`、巴黎楼 `CAPARS04` | 50000 |
| | 核电站 `NANRCT` | 32000 |
| | `NAMISL`、`PDPLANE` | 100000 / 32000 |
| | 苏军基地 `NACNST` | 30000 |
| | 盟军电厂 `GAPOWR`、`MAYAN` | 8500 / 2000 |
| 苏军任务 `maps02.mix` | 上面那些 + 弗拉基米尔的指挥舰 `DRED` / `VLAD` | 10000 |
| | 精神信标 `NAPSYB`、巴黎塔 `CAPARS01` | 2500 / 30000 |
| | 灯柱 `INGALITE` | 6000 |
| 联机图 `MULTI.MIX` | 灯柱 `INGALITE` | 6000 |
| `Hills.mmx` | `CABUNK01` | 2000 |

**唯一一个额外加厚的**：

| 位置 | 类型 | 原值 → 现值 | 原因 |
|---|---|---|---|
| 盟军第一关 | 自由女神像 `CANEWY04` | 10000 → **99999** | 全员 1500 血后，进攻方也变硬、清不动，10 万血才守得住 |

> 苏军第三关（`maps02.mix`）的女神像保持任务原值 10000。

## 数值与规则

| 键 | 值 | 说明 |
|---|---|---|
| `Strength`（406 处） | **1500** | 所有单位/建筑 |
| `TreeStrength` / `BridgeStrength` | **1500** | 树 / 桥 |
| `[DeathDummy]` | 补 `Strength=1500` | 原版没这个键，0 血会触发维修除零 |
| `RepairStep` / `IRepairStep` | **8 / 20（原版）** | `1500/8=187`，不会像 5 血那样除零；**不需要**打 exe 补丁 |
| `game.exe` | **不动** | 5 血那个 `mov eax,5` 补丁会让 1500 血的维修费翻 5 倍，本模式绝不能打 |
| `MaxDebris` | ≤ 4（189 处） | 降负载：碎片变少 |
| `MinDebris` | ≤ 1（181 处） | 同上 |
| `DamageParticleSystems` | 每类 1 套（106 处） | 降负载：烟尘变少 |
| `[OilExplosionWH] DelayKillFrames` | 15 | 连环爆分帧更明显 |

> 降负载只动**画面特效**，`DeathWeapon=` / `CausesDelayKill=` / `CellSpread=` 这些**连锁伤害一个都没改**。
> 苏军第三关结尾"大批单位被控制"那里曾崩过一次（`EXCEPTION_ACCESS_VIOLATION` @ `0x787B2A`，链表+位图写野指针），加降负载就是为了压这类"内存被写坏"的崩。

## 安装

### 方式一：一键脚本（推荐）

```bash
python apply_tanky_mod.py "D:\RAY2\红色警戒2 完整版"
```

脚本会：
1. 把要改的文件先备份到 `<游戏目录>\_tanky_backup\`
2. 覆盖 `rules.ini`（全员 1500 + 降负载）
3. 改 5 个原版任务包/地图里**地图自带的血量覆盖**（等长替换，不破坏数据包）
4. 给盟军第一关的自由女神像加厚到 99999
5. 确认 `game.exe` 是原版未打补丁（被打过就自动还原）

撤销（从备份还原）：

```bash
python apply_tanky_mod.py "D:\RAY2\红色警戒2 完整版" --undo
```

只看当前状态（不改任何东西）：

```bash
python apply_tanky_mod.py "D:\RAY2\红色警戒2 完整版" --check
```

### 方式二：小白包

下载 `bundle/` 里的 3 个文件，双击「一键应用.bat」，把游戏目录拖进去回车。

> ⚠️ **改完必须完全退出游戏再重开**（规则只在启动时读一次）。
> ⚠️ **应用后请新开关卡/遭遇战，不要读旧存档**：红警的存档自带当时的场景数据（含各类型血量），
> 读旧档会继续用旧数值——这个坑真的会让人以为"改了没用"。

## 技术细节：任务包为什么只能"等长"改

任务包（`.mix` / `.mmx` / `.yro`）的索引用 Blowfish 加密，里面记着每个文件的偏移和长度。**动长度就得重写加密索引**，风险极高，所以本仓库一律**等长替换**（文件大小一个字节都不变）。

三类覆盖，三种改法：

| 情况 | 处数 | 做法 |
|---|---|---|
| 类型在 `rules.ini` 里有段落 | 95 | 把它那句 `Strength=` 的 `S` 改成 `;`（`;trength=1500`，等长注释掉），让它回落到 `rules.ini` 的 1500 |
| 任务图内自带类型、原值 ≥ 4 位 | 11 | 原地写成 `Strength=1500`（多余位用空格补齐，等长） |
| 任务图内自带类型、原值只有 1~3 位 | 18 | 值扩成 `1500` 会多出 1~3 字节，就在**同一段落内**删掉等量字节（空行 / 注释行 / 重复的语音列表项），净长度不变 |

自查脚本随仓库提供思路：改完对比原版备份，`[Basic]` / `[Header]` / `[Map]` / `[MultiMaps]` / `[Digest]` / `[IsoMapPack5]` / `[Structures]` / `[Units]` / `[Triggers]` / `[Waypoints]` 这些结构标记数量必须**一个不差**，段总数也要一致——这能证明没有哪张图的头被切掉。

为什么"原值 > 1500 就保留"：那不是"漏改"，是关卡作者故意做硬的目标。压到 1500 会让盟军第一关的女神像一开局就被拆掉（关卡直接失败）。
