# 皮糙肉厚的红警（由 AI 制作）

> 把所有单位、建筑、树木、桥梁的血量全部改成 **1500** —— 也就是**原版船厂**（`[GAYARD]` / `[NAYARD]`）的血量。
> 步兵跟船厂一样硬，坦克要磨很久才死，一枪一栋楼？不存在的。
>
> **两个版本都支持**：原版红警2（`rules.ini`）+ 尤里的复仇（`rulesmd.ini`）。
>
> 本仓库**不包含任何游戏本体文件**，只提供规则文件、一键脚本与技术文档。请自备正版游戏。
> 姐妹玩法（另一个极端）：[crispy-ra2-ai](https://github.com/YZB-127/crispy-ra2-ai) —— 全员 5 血，一枪一栋楼。

## 这个玩法是什么

| 项目 | 原版 | 皮糙肉厚 |
|---|---|---|
| 步兵 | 75 ~ 125 | **1500** |
| 载具 / 飞机 | 300 ~ 800 | **1500** |
| 建筑 | 750 ~ 1500 | **1500** |
| 树木 / 桥梁 | 200 / 1500 | **1500** |
| 结果 | 正常交火节奏 | **谁都得磨半天，步兵都啃不动** |

选 1500 是因为它正好是**原版船厂的血量**（YR 的 `[YAYARD]` 也是 1500），也就是"全员按船厂的硬度来"。
所以这个模式更接近"拆迁队 vs 钉子户"：海量单位围着打也拆不快，油桶连锁、核电站殉爆那种一炸一片的爽感会被大幅削弱——那是 5 血版的乐趣，不是这版的。

## 数值与规则

| 键 | 值 | 说明 |
|---|---|---|
| `Strength` | **1500** | 所有单位/建筑（原版 406 处 + 尤里 555 处） |
| `TreeStrength` / `BridgeStrength` | **1500** | 树 / 桥 |
| 0 血类型 | 补 `Strength=1500` | 原版 `[DeathDummy]` 缺键；尤里还有 2 个缺键 + 6 个段落缺失，0 血会触发维修除零 |
| `RepairStep` / `IRepairStep` | **8 / 20（原版）** | `1500/8=187`，不会像 5 血那样除零；**不需要**打 exe 补丁 |
| `game.exe` / `gamemd.exe` | **完全不动** | 5 血那个 `mov eax,5` 补丁会让 1500 血的维修费翻 5 倍，本模式绝不能打 |
| `MaxDebris` / `MinDebris` | ≤ 4 / ≤ 1 | 降负载：碎片变少 |
| `DamageParticleSystems` | 每类 1 套 | 降负载：烟尘变少 |
| `[OilExplosionWH] DelayKillFrames` | 15 | 连环爆分帧更明显 |

> 降负载只动**画面特效**，`DeathWeapon=` / `CausesDelayKill=` / `CellSpread=` 这些**连锁伤害一个都没改**。
> 苏军第三关结尾"大批单位被控制"那里曾崩过一次（`EXCEPTION_ACCESS_VIOLATION` @ `0x787B2A`，链表+位图写野指针），加降负载就是为了压这类"内存被写坏"的崩。

## 安装

### 方式一：一键脚本（推荐）

```bash
python apply_tanky_mod.py "D:\RAY2\红色警戒2 完整版"          # 只改原版红警2
python apply_tanky_mod.py "D:\RAY2\红色警戒2 完整版" --yr     # 只改尤里的复仇
python apply_tanky_mod.py "D:\RAY2\红色警戒2 完整版" --all    # 两个都改
```

脚本会：
1. 把要改的文件先备份到 `<游戏目录>\_tanky_backup\`（原版）/ `_tankymd_backup\`（尤里）
2. 写入规则文件（原版 `rules.ini`、尤里 `rulesmd.ini`：全员 1500 + 降负载）
3. 改任务包/地图里**地图自带的血量覆盖**（等长替换，不破坏数据包）
4. 原版额外：盟军第一关女神像加厚到 99999；确认 `game.exe` 是原版未打补丁

撤销 / 查状态：

```bash
python apply_tanky_mod.py "D:\RAY2\红色警戒2 完整版" --undo        # 还原原版那边
python apply_tanky_mod.py "D:\RAY2\红色警戒2 完整版" --yr --undo   # 只还原尤里那边
python apply_tanky_mod.py "D:\RAY2\红色警戒2 完整版" --all --undo  # 两个都还原
python apply_tanky_mod.py "D:\RAY2\红色警戒2 完整版" --check       # 只看状态
```

### 方式二：小白包

下载 `bundle/` 里的文件，双击「一键应用.bat」（原版）或「一键应用(尤里).bat」，把游戏目录拖进去回车。

> ⚠️ **改完必须完全退出游戏再重开**（规则只在启动时读一次）。
> ⚠️ **应用后请新开关卡/遭遇战，不要读旧存档**：红警的存档自带当时的场景数据（含各类型血量），
> 读旧档会继续用旧数值——这个坑真的会让人以为"改了没用"。

## 技术细节（摘要，详见 [`docs/技术细节.md`](docs/技术细节.md)）

### 任务包为什么只能"等长"改

任务包（`.mix` / `.mmx` / `.yro`）的索引用 Blowfish 加密，里面记着每个文件的偏移和长度。**动长度就得重写加密索引**，风险极高，所以一律**等长替换**（文件大小一个字节都不变）。

三类覆盖，三种改法：

| 情况 | 做法 |
|---|---|
| 类型在规则文件里有段落 | 把它那句 `Strength=` 的 `S` 改成 `;`（等长注释掉），回落到规则文件的 1500 |
| 任务图内自带类型、原值 ≥ 4 位 | 原地写成 `Strength=1500`（多余位用空格补齐，等长） |
| 任务图内自带类型、原值只有 1~3 位 | 值扩成 `1500` 会多出 1~3 字节，就在**同一段落内**删掉等量字节（空行 / 注释行 / 重复的语音列表项），净长度不变 |

改完必须自查：文件大小、段总数、`[Basic]` `[Header]` `[Map]` `[MultiMaps]` `[Digest]`
`[IsoMapPack5]` `[Structures]` `[Units]` `[Triggers]` `[Waypoints]` 出现次数必须与原版**一个不差**，
且不能出现 `asic]` 这类断头残片。

### 尤里的复仇：规则不在散装文件里怎么办

原版有散装 `rules.ini`，尤里**没有** —— 它的 `rulesmd.ini` 打包在 `expandmd01.mix` / `ra2md.mix` 里，
而这些包的索引是加密的。**不用去啃加密索引**：

> `rulesmd.ini` 自己的抬头就写着：*If placed in game directory, it will override built in values.*

也就是说，**往游戏目录放一份散装 `rulesmd.ini` 就能盖住打包里那份**。本仓库就是这么做的：
从包里把那份规则以**纯文本方式**取出来（它在包里是不压缩的明文），改好，放到游戏目录。
打包文件一个字节都不用动。

> 顺便说个坑：这整合版里有 3 份 `rulesmd.ini`（`expandmd01.mix`、`ra2md.mix`、`expand01.mix`）。
> YR 的加载顺序是 `expandmd*` → `ra2md` → `expand*`，**先命中先用**，所以实际生效的是 `expandmd01.mix` 那份；
> `expand01.mix` 那份被人改过（有 `;zhuijianspy` 之类），不是基线。
